# Appwrite Setup Guide for System: You

## Overview
This project uses Appwrite as the backend database for storing self-development resources.

## Required Environment Variables

Create a `.env` file in your project root with these variables:

```env
# Appwrite Configuration
APPWRITE_ENDPOINT=https://your-appwrite-instance.com/v1
APPWRITE_PROJECT_ID=your-project-id
APPWRITE_DATABASE_ID=your-database-id
APPWRITE_COLLECTION_ID=your-collection-id
```

## Appwrite Database Structure

### Database Setup
1. **Database Name**: `system-you` (or whatever you prefer)
2. **Collection Name**: `resources`

### Collection Schema
The `resources` collection should have these attributes:

| Attribute | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `title` | String | Yes | - | Resource title |
| `category` | Enum | Yes | - | Type: `book`, `article`, `video`, `podcast` |
| `createdBy` | String | Yes | - | Author/Creator name |
| `description` | String | Yes | - | Resource description |
| `url` | String | No | - | Link to resource (optional) |
| `imageUrl` | String | No | - | Cover image URL (optional) |

### Collection Permissions
- **Read**: `any` (public read access)
- **Create**: `users` (authenticated users can add resources)
- **Update**: `users` (authenticated users can edit)
- **Delete**: `users` (authenticated users can delete)

## Resource Data Structure

```typescript
type AppwriteResource = {
  $id: string;           // Auto-generated by Appwrite
  title: string;         // "Atomic Habits"
  category: 'book' | 'article' | 'video' | 'podcast';
  createdBy: string;     // "James Clear"
  description: string;   // "A comprehensive guide to building good habits..."
  url?: string;          // "https://jamesclear.com/atomic-habits"
  imageUrl?: string;     // "https://example.com/book-cover.jpg"
  $createdAt: string;    // Auto-generated timestamp
  $updatedAt: string;    // Auto-generated timestamp
};
```

## API Endpoints

### GET /api/resources
Returns all resources from the collection.

### GET /api/resources/[id]
Returns a specific resource by ID.

## Installation

```bash
npm install node-appwrite
```

## Server Functions

The server functions are located in `src/lib/server/appwrite.ts`:

- `getResources()` - Fetches all resources
- `getResourceById(id)` - Fetches a specific resource

## Testing the Setup

1. Add some test data to your Appwrite collection
2. Update the API routes to use real Appwrite instead of mock data
3. Test the resources page to ensure data loads correctly

## Migration from Mock Data

To switch from mock data to real Appwrite:

1. Install `node-appwrite`: `npm install node-appwrite`
2. Add your environment variables to `.env`
3. Uncomment the real Appwrite code in `/src/routes/api/resources/+server.ts`
4. Remove the mock data array
